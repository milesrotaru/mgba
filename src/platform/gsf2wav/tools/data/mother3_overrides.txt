# Per-track gsf2wav options for Mother 3 (2006-04-20 rip), applied by
#   render_set.py ... --overrides tools/data/mother3_overrides.txt
# Format: track filename prefix (up to the first space), then gsf2wav options.
# Options here are added after the set-wide ones, so they can override them.

# 006's organ (082ED1BC) used to be rendered like the driver
# (--mp2k-linear-samples) because it was gritty in sinc mode. The grit was the
# rip's holes: bytes the ripper never saw read, zeroed. With the holes filled,
# or the real data read from the game ROM (--sample-rom), it no longer needs it.

# Peaks at +2.2 dBFS; lower it so integer and lossy output doesn't clip.
918 -g -3

# Float peaks just under 0 dBFS, but Opus encoding overshoots them past it
# (+0.07 to +0.36 dBFS decoded); bring each to about -1.2 dBFS.
001 -g -1.0
242 -g -1.1
249 -g -0.9
